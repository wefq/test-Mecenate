# test-Mecenate

Мобильное приложение на `Expo` и `React Native` для отображения ленты постов Mecenate.

## Требования

- `Node.js`
- `npm`
- `Expo Go` на устройстве или настроенный эмулятор/симулятор

## Запуск проекта

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Создать локальный env-файл:

   Windows:

   ```powershell
   Copy-Item .env.example .env
   ```

   macOS / Linux:

   ```bash
   cp .env.example .env
   ```

3. Заполнить `.env` значениями для вашего окружения.

4. Запустить dev-сервер Expo:

   ```bash
   npm run start
   ```

5. Открыть приложение:

- `npm run android` - запуск на Android
- `npm run ios` - запуск на iOS (требуется macOS)
- `npm run web` - запуск в браузере

Также после `npm run start` можно использовать горячие клавиши Expo CLI: `a`, `i`, `w`.

## Переменные окружения

Приложение читает env-переменные через `process.env`. Сейчас используется одна обязательная переменная:

| Переменная | Обязательная | Описание |
| --- | --- | --- |
| `EXPO_PUBLIC_API_URL` | да | Базовый URL API, к которому приложение делает запросы. Указывайте значение без завершающего `/`. |

Пример:

```env
EXPO_PUBLIC_API_URL=https://api.example.com
```

Важно: переменные с префиксом `EXPO_PUBLIC_` попадают в клиентское приложение. Не храните в них секреты, приватные токены и пароли.

## Полезные команды

- `npm run start` - старт Expo dev server
- `npm run android` - открыть Android-сборку
- `npm run ios` - открыть iOS-сборку на macOS
- `npm run web` - открыть web-версию
- `npm run lint` - проверить проект линтером

## Примечания

- Пользовательский токен вручную задавать не нужно: приложение генерирует UUID при первом запуске и сохраняет его в `AsyncStorage`.
- После изменения `.env` перезапустите Expo dev server, чтобы новые значения подхватились.
- Если API недоступен или `EXPO_PUBLIC_API_URL` указан неверно, экран ленты вернёт состояние ошибки при загрузке постов.
